Política de privacidade

ConHub CRM · conhubcrm.com.br · atualizada em 01/10/2026

O ConHub é um sistema de atendimento (CRM) usado por imobiliárias e corretores de imóveis para organizar os contatos que recebem de clientes interessados. Esta página explica quais dados o ConHub trata, para quê, e como pedir acesso ou exclusão.

Quem é responsável pelos dados

Cada imobiliária ou corretor que usa o ConHub decide quais contatos atender e como; pela Lei Geral de Proteção de Dados (LGPD), ela é a controladora dos dados dos seus clientes. O ConHub é o operador: trata esses dados em nome dela, só para prestar o serviço contratado.

Quais dados tratamos

  • Dos clientes das imobiliárias (leads): nome, telefone, e-mail, as respostas dadas em formulários de anúncio (por exemplo, renda ou prazo para comprar), as conversas de WhatsApp com a imobiliária e as anotações feitas pela equipe.
  • Da equipe que usa o sistema: nome, e-mail, telefone e senha (guardada de forma irreversível).
  • Do Facebook e do Instagram, quando a imobiliária conecta a página: a lista das páginas que a pessoa administra, para ela escolher qual conectar; uma chave de acesso da página escolhida, guardada criptografada; e os dados dos leads dos formulários de anúncio daquela página (nome, telefone, e-mail, respostas, e o nome da campanha e do formulário).

Para que usamos

  • Entregar à imobiliária os contatos que chegam pelos anúncios, pelo WhatsApp e pelos portais, para que ela possa atender.
  • Mostrar à imobiliária relatórios do próprio atendimento.
  • Quando a imobiliária pede, gerar resumos e sugestões a partir das conversas com uma ferramenta de inteligência artificial — só no clique, nunca de forma automática para todos os contatos.

Não vendemos dados, não usamos os dados de uma imobiliária para outra e não usamos dados do Facebook ou do Instagram para publicidade.

Com quem os dados são compartilhados

Apenas com os fornecedores necessários para o serviço funcionar, que tratam os dados em nosso nome: hospedagem do sistema, armazenamento de arquivos, envio de e-mails, o provedor de WhatsApp contratado pela imobiliária e o provedor de inteligência artificial (somente quando a imobiliária usa esse recurso).

Por quanto tempo

Enquanto a imobiliária mantiver a conta no ConHub ou até ela pedir a exclusão. Ao desconectar uma página do Facebook, a chave de acesso dela é apagada na hora.

Segurança

O acesso ao sistema exige login, cada imobiliária só enxerga os próprios dados e as chaves de acesso das páginas do Facebook ficam criptografadas.

Seus direitos

Pela LGPD, você pode pedir para saber quais dados seus existem, corrigi-los ou pedir que sejam eliminados. O caminho mais rápido é falar com a imobiliária com quem você conversou: ela consegue exportar ou anonimizar seus dados direto no sistema. Você também pode falar com o ConHub pelos contatos do site conhubcrm.com.br. Para excluir dados vindos do Facebook, veja como pedir a exclusão.
